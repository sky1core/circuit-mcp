# @sky1core/circuit-web

Web browser automation MCP server for AI agents.

## Features

- **Playwright mode**: Launch new browser (Chromium/Firefox/WebKit)
- **Extension mode**: Control user's actual Chrome browser with `browser_connect`
- **Multi-client**: Multiple AI agents can work simultaneously
- **33+ tools**: navigate, click, type, screenshot, snapshot, and more

## Quick Start

```json
{
  "mcpServers": {
    "circuit-web": {
      "command": "npx",
      "args": ["-y", "@sky1core/circuit-web"]
    }
  }
}
```
