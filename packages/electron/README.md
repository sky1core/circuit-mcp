# @sky1core/circuit-electron

Electron desktop app automation MCP server for AI agents.

## Features

- **Any Electron app**: Packaged (.app, .exe) or development mode
- **IPC communication**: Direct inter-process communication
- **File system access**: Read/write files in app context
- **32+ tools**: app_launch, click, type, screenshot, ipc_invoke, and more

## Quick Start

```json
{
  "mcpServers": {
    "circuit-electron": {
      "command": "npx",
      "args": ["-y", "@sky1core/circuit-electron"]
    }
  }
}
```
